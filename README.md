# 🏡 WanderLust

**WanderLust** is a full-stack web application inspired by **Airbnb**, built using the **MERN stack (MongoDB, Express.js, React.js, Node.js)**.  
It allows users to explore, list, and book vacation rentals from around the world with an intuitive, modern interface.

---

## 🚀 Features

### 🌍 User Features
- 🔐 **User Authentication & Authorization** — Secure login/signup with password hashing using **bcrypt** and session management with **JWT**.  
- 🏠 **List a Property** — Users can create new listings with images, price, and location details.  
- 🔎 **Search & Filter** — Find stays based on location, price, or category.  
- ❤️ **Wishlist/Favorites** — Save listings for later exploration.  
- 🗺️ **Interactive Map View** — View property locations on an integrated **Mapbox** map.  
- 💬 **Reviews & Ratings** — Leave feedback and read others' experiences.  
- 📱 **Responsive Design** — Optimized for mobile, tablet, and desktop views.

### ⚙️ Admin / Host Features
- ✏️ Edit and delete existing listings.  
- 📸 Upload images using **Cloudinary** for fast and secure media hosting.  
- 🧾 Manage reviews and bookings.
